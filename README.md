# Projetos de Design Gráfico 🎨

Este repositório reúne projetos acadêmicos e pessoais desenvolvidos durante minha formação em Design Gráfico.

## Sobre os projetos

Aqui estão trabalhos relacionados a:

* Identidade visual
* Branding
* Direção de arte
* Design gráfico
* Edição de imagens
* Conteúdo digital

## Ferramentas

* Adobe Photoshop
* Adobe Illustrator
* Adobe Premiere
* Canva
* Outras ferramentas de criação e edição

## Objetivo

Organizar e apresentar parte dos meus projetos e trabalhos desenvolvidos durante minha formação, mostrando minha evolução e minhas principais áreas de interesse dentro do Design.
